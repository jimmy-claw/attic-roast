# Logos Attic Coffee — branding

Coffee branding for the **Logos Attic** coffee session at **Dark Prague 2026**
(Old Wastewater Treatment Plant, Prague). A numbered edition of 50 bags.

- `index.html` — the branding site
- `labels/` — label sources (HTML/CSS, rendered to exact mm by `../render.sh`)
- `downloads/` — print-ready PDFs + 300 DPI PNGs
- `logos-attic-coffee-print-kit.zip` — everything

Palette: ink `#0C0C0D` · bone `#F4F3EC` · sage `#A7AFA9` · ember `#E2542B`
Type: Anton · Space Grotesk · IBM Plex Mono
